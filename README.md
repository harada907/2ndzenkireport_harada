デュエル・マスターズデジタル ファイリングアプリ

カードの情報を登録して
所持枚数を管理するためのアプリです

起動はmainから


1.カード情報を登録するのは 登録

2.全てのカード枚数情報を出す 1.全表示モード

L お目当てのカード情報を入れて登録されているカードの中からスペックをみて割り出す 2.検索表示モード

Lカードの詳細な登録スペックを表示する 3.IDでカード詳細表示モード

3.カード情報の更新、修正を行う 更新

4.カードの情報をID指定して削除する 削除

5.登録や修正,削除を行なった情報をCSV保存してプログラム全体を終了する 終了

実行環境:コンソール ターミナル
